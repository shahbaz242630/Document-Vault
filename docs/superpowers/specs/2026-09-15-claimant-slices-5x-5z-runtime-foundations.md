# Combined Slices 5X–5Z — claimant runtime foundations

Selected together on 2026-09-15 as one bounded stacked delivery after Slice 5W was published in PR #87. The combined slice adds three independently literal-false, runtime-disconnected mobile foundations: a hosted identity/MFA source boundary, a production-shaped native handoff-signing boundary restricted to synthetic test aliases, and one separately isolated composition root that joins them to the existing Slice 5U–5V session journey.

Slice 5X accepts only an injected synthetic hosted-identity provider. The provider must synchronously establish one exact issuer/audience-bound, fresh non-recovery AAL2 session and return a valid cleanup function. The boundary exposes that session only through the existing synthetic subscription shape. Malformed, stale, AAL1, recovery, issuer/audience-substituted, asynchronously established or drifting authentication closes permanently. Snapshots are value-free. No Supabase SDK, token refresh, sign-in UI, browser/session persistence or ambient authentication access is included.

Slice 5Y accepts only an injected native-shaped signer marked synthetic and restricted to an exact test alias/fingerprint. It passes the already validated handoff transcript bytes, challenge ID and record-binding digest to the injected native method under an abort signal. A successful result must be an exact synthetic response bound to the same alias/fingerprint, a valid Ed25519 signature, verified user presence and explicit private-key non-exportability. It exposes only the signature to the existing handoff coordinator and retains no transcript or signature. Cancellation, overlap, disposal, malformed/expanded output, alias/fingerprint drift, missing user presence or exportability claims fail generically. No native module import, production alias/entitlement, key creation/recovery, private key, physical-device claim or direct platform binding is included.

Slice 5Z creates the 5X and 5Y boundaries only inside one independently literal-false, runtime-disconnected composition root, then supplies their source/signer to the existing Slice 5U–5V journey. It delegates portal activation, fresh assertion, possession, authenticated handoff, exact retries, cancellation, revoke and awaitable disposal while exposing only a generic value-free snapshot and the established value-free draft. It has no normal application importer, UI/navigation, ambient network/auth/native/storage/provider access or activation mechanism.

Acceptance covers dormant dependency non-access for all three gates; strict synchronous fresh-AAL2 issuer/audience validation; authentication drift closure; exact test alias/fingerprint and user-presence validation; abort/late-result/overlap/disposal behavior; full injected route-to-draft composition; assertion-before-native signing; exact activation/proof/completion/revoke retry delegation; background and terminal lifecycle behavior; generic errors; frozen value-free snapshots/results; dedicated static isolation and sole-wrapper rules; focused tests, all workspace tests/typechecks/lint/security/isolation, API bundle and web production build.

No hosted Auth mutation, actual MFA enrolment or provider session, production native custody/signing, normal claimant UI/navigation, persistent claimant state, server/database/migration change, provider/notification integration, deployment, preview promotion, native/EAS build, real claimant data, downstream intake/review/release runtime authority or capability activation is included.
