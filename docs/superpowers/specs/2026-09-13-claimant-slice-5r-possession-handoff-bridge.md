# Slice 5R — synthetic possession-to-handoff bridge

Selected on 2026-09-13 while Slice 5Q remained open in PR #79. Build a separate, literal-false mobile composition root that runs the existing offline-code V2 possession lifecycle and authenticated handoff lifecycle in one foreground-only synthetic attempt. The bridge must obtain the source challenge ID and record-binding digest from the validated proof request only after the proof API returns its strict `proof_verified` response. The caller cannot assert possession or supply that source to handoff.

Capture an AAL2 claimant-portal session before proof and require the same user, session ID and version immediately after proof, throughout handoff, and on retry. A session mismatch permanently closes and clears the bridge. One strictly ordered lifecycle source fans out to both child scopes. Inactive/background cancels work and clears retries; lock, session end, disable, malformed or regressing events close permanently. Suppress late proof and handoff results. Retry only the existing bounded, exact public proof or signed completion in the same foreground/session scope; never regenerate a proof or replay after a lifecycle transition. The result remains a session-bound draft case with all identity, relationship, intake, review, and release flags false.

Acceptance: dormant-by-default dependency non-access; injected synthetic proof-to-draft success; source ID/digest from verified proof; no handoff for rejected proof; session swap and revert denial; background suppression; exact proof and completion retry; missing or terminal lifecycle denial; no normal runtime importer, ambient provider, native adapter, persistent secret, feature activation or hosted mutation; focused regression, typecheck, lint and security isolation checks.

The bridge is not an app route or production claimant journey. Production custody/signing, hosted MFA, claimant UI/session wiring, protected-preview smoke, native builds, and real claimant acceptance remain separate work. PR #79's staging smoke blocker remains separate from this local slice.
